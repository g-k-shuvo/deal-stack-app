Security & Compliance

Enterprise-grade security for sensitive deal data

M&A deals involve some of the most confidential business data in existence. DealStack is built with that responsibility in mind.

🔐

256-bit AES Encryption

All data encrypted at rest and in transit using bank-grade encryption standards.

👤

Granular Access Controls

Control exactly who sees what — down to the individual document or data room folder.

📋

Full Audit Trail

Every document view, download, and access event is logged with timestamp and user identity.

🛡️

SOC 2 Type II

Annual third-party security audits with SOC 2 compliance certification (in progress).

🌐

U.S. Data Residency

All data stored on U.S.-based servers. No offshore processing of confidential deal data.

🔑

Two-Factor Authentication

Mandatory 2FA for all users, with SSO support for enterprise plans.
